# Fonts that Fedora doesn't package. Installed by `./install.sh fonts` into
# ~/.local/share/fonts/dotfiles/<name>/ (per user, no root, no extra repo).
#
# Format:  <name>  <sha256>  <url>
# Every download is pinned to an exact version and checked against its sha256.
# To update a font: change the URL, run `sha256sum` on the new file, update the hash.
# .zip files are unpacked (only .ttf/.otf are kept); .ttf/.otf are copied as-is.
