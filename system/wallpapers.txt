# Photos from Unsplash (https://unsplash.com/license: free to use). Downloaded by `./install.sh wallpapers`
# into ~/.local/share/wallpapers/<name>.jpg. They are not stored in this repo. Files there that are not
# listed here are removed by the same step (your own images go in ~/Pictures/Wallpapers and are never touched).
#
# Format:  <name>  <sha256>  <url>
# Each URL asks Unsplash's image CDN for a 2560x1600 smart crop at quality 90 (so portrait photos fit a landscape screen;
# a 16:9 monitor shows it with a strip off the top and bottom). Pick originals at least ~4800 px wide: the CDN then
# scales down, which keeps them sharp on a 1440p monitor (smaller ones get scaled up and look soft).
# The CDN returns identical bytes every time, so the checksums are pinned. A failed download or a changed
# checksum only skips that photo with a warning; it never stops the install.
# Photographer names are not recorded here (Unsplash blocks automated page lookups). To add one, find the
# photo on unsplash.com and note it in the comment.
#
# To add a photo: take the long id from its image URL (photo-<id>), build the URL below, download it once,
# run `sha256sum` on it, and add a line. To remove one, delete its line (and the file).

# The set: natural and muted, to go with the palette; checked at 100% for sharpness.
